# Dynasty 8 — Agent Terminal

Single-page agent terminal for Dynasty 8 realtor roleplay. Everything runs in the browser; there is no server or build step.

**Live site:** https://shadstradamus.github.io/HUG-Realtor-Tool/

## Data

Listings, clients and settings are saved in your browser (localStorage + IndexedDB) on whatever device you open the site from. Nothing is uploaded anywhere. Use **Export backup** regularly, and use import to move your data to another browser or device.

## Updating

Replace `index.html` with the new version and commit. GitHub Pages republishes in a minute or two.
